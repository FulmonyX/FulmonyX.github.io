FMB2026w001 ImageFrame v2026.1.4.0 高危 7.8
DDoS · RCE
依赖的图像处理器在处理特制 GIF 时存在越界写入漏洞，可导致 RCE 或 拒绝服务。

利用方式：构造特制 GIF 图片，通过 ImageFrame 上传或加载，触发图像处理器越界写入

FMB2026w002 Geyser-Spigot v2.11.0-SNAPSHOT 中危 6.2
信息泄露
处理基岩版玩家皮肤时，恶意图片 URL 会导致服务器向外部发起请求，可能泄露 服主个人信息。

利用方式：设置恶意皮肤 URL（指向攻击者控制的服务器），Geyser 服务端会主动发起 HTTP 请求，暴露内网 IP、服务端版本等敏感信息
影响：攻击者可获取服务器真实 IP、地理位置、服务端指纹，为进一步攻击提供信息
修复：升级 Geyser 到最新版本，或在防火墙层限制服务端出站请求
FMB2026w003 AuthMe v6.0.0-b2734 中危 5.4
时间侧信道
comparePassword 使用逐字符比较，正确/错误密码响应时间存在差异，攻击者可发送大量请求 推断管理员密码。

利用方式：批量发送登录请求，记录服务器响应时间，利用时间差逐字符爆破密码
影响：在理想网络条件下，攻击者可能恢复管理员密码，导致账号完全被接管
修复：使用 MessageDigest.isEqual() 进行恒定时间比较，或升级到已修复该问题的 AuthMe 版本
FMB2026w004 /msg /tell /w 低危 0.1
权限设置错误
没有op权限的玩家无法使用/msg /tell /w /help等指令

利用方式：无恶意利用场景，属于功能性权限配置错误，影响普通玩家正常交流

FMB2026w005 AuthMe 全版本（离线模式） 高危 7.5
身份混淆 · 拒绝服务
AuthMe 登录冲突检查使用 startsWith() 前缀匹配而非 equalsIgnoreCase() 精确匹配。

任意玩家注册 {目标名}+任意后缀（如 Admin_chat、Admin_backup）并保持在线，即可永久阻止目标玩家（如 Admin）登录，提示"已有同名用户在线"。

利用方式：注册 目标名任意后缀 → 保持在线 → 目标玩家永久无法登录
影响：全服任意玩家可被定向攻击，管理员账号亦无法幸免
修复：将 startsWith 改为 equalsIgnoreCase
